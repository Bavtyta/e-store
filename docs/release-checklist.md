# Release checklist

Этот checklist применяется к каждому staging/production-релизу storefront. Публичный
production-релиз сейчас заблокирован до выполнения миграции из
[ADR-0001](adr/0001-rendering-strategy.md).

## Архитектурные блокеры

- [ ] Реализована отдельная миграционная задача React Router Framework Mode.
- [ ] Главная, контакты, политика и соглашение отдаются как prerendered HTML.
- [ ] Каталог, категории и товары отдаются через SSR.
- [ ] Неизвестные маршруты и сущности возвращают HTTP `404`, а необработанные серверные
      ошибки — HTTP `500`.
- [ ] Корзина остаётся клиентской, имеет `noindex, nofollow` и корректно гидратируется.
- [ ] SSR, prerendering, hydration и HTTP-статусы покрыты автоматическими тестами.

## Код и CI

- [ ] Изменения прошли review; незапланированная бизнес-функциональность отсутствует.
- [ ] Используется закоммиченный `package-lock.json`, зависимости устанавливаются через
      `npm ci`.
- [ ] `npm run format:check` выполнен успешно.
- [ ] `npm run lint` выполнен успешно.
- [ ] `npm run typecheck` выполнен успешно.
- [ ] `npm run test` выполнен успешно.
- [ ] `npm run build` выполнен с целевыми переменными окружения.
- [ ] `npm run verify:production-output` подтвердил отсутствие MSW worker, handlers и
      fixtures.
- [ ] `npm run test:e2e` выполнен успешно.
- [ ] В CI нет отключённых проверок, незакреплённых секретов и deployment-прав.

## Контракты и конфигурация

- [ ] Версия OpenAPI согласована с развёртываемым backend.
- [ ] API DTO проходят актуальные Zod-схемы и contract-тесты.
- [ ] `VITE_APP_ENV` соответствует окружению: `staging` или `production`.
- [ ] `VITE_MSW_ENABLED=false`.
- [ ] `VITE_PUBLIC_SITE_URL` содержит фактический HTTPS origin без path/query/hash.
- [ ] `VITE_API_BASE_URL` указывает на same-origin `/api/v1` или разрешённый HTTPS API.
- [ ] Опциональные analytics/error-reporting идентификаторы публичны и не являются
      секретами.
- [ ] Секреты backend/runtime не имеют префикса `VITE_` и недоступны клиентскому bundle.

## Функциональная и визуальная проверка

- [ ] На staging вручную проверены главная, каталог, вложенная категория и товар.
- [ ] Проверены поиск, сортировка, пагинация и пустой результат.
- [ ] Проверены выбор варианта, цена, SKU, наличие и товар без изображения.
- [ ] Проверены добавление, изменение количества, удаление, очистка и восстановление
      корзины.
- [ ] Проверены безопасные UI для API `404`, `500`, сетевой ошибки и повреждённого ответа.
- [ ] Проверены прямой вход и обновление страницы на каждом публичном маршруте.
- [ ] Нет горизонтального переполнения на ширинах 320, 375, 768, 1024 и 1440 px.

## Доступность и SEO

- [ ] Основные сценарии полностью выполняются с клавиатуры; focus state видим.
- [ ] На каждой странице ровно один `main` и один `h1`; skip-link работает.
- [ ] Поля, radiogroup, диалоги и live regions имеют корректные доступные имена.
- [ ] Автоматический accessibility-аудит и ручная проверка screen reader не выявили
      блокирующих проблем.
- [ ] Индексируемые маршруты имеют уникальные title, description и canonical.
- [ ] Корзина, ошибки, 404 и служебные маршруты не индексируются.
- [ ] `robots.txt`, `sitemap.xml` и при необходимости Schema.org соответствуют реальному
      production origin.
- [ ] Проверены Core Web Vitals и бюджеты производительности на staging.

## Безопасность

- [ ] Включён HTTPS; HTTP перенаправляется на HTTPS.
- [ ] Security headers из
      [deployment requirements](deployment-requirements.md) настроены и проверены.
- [ ] CSP сначала проверена в report-only режиме, затем переведена в enforce без
      необоснованно широких источников.
- [ ] Missing assets и `/api/*` не переписываются на SPA/HTML fallback.
- [ ] Production source maps публикуются только при согласованной политике доступа.
- [ ] `npm audit` и согласованный dependency/security scan не содержат блокирующих
      уязвимостей.
- [ ] В bundle, логах и network-запросах нет секретов и лишних персональных данных.

## Наблюдаемость и эксплуатация

- [ ] Выбран и подключён внешний observability-адаптер либо письменно принят риск no-op
      режима.
- [ ] Privacy review подтвердил allowlist отправляемых полей.
- [ ] Настроены uptime, API/SSR latency, error rate и Core Web Vitals.
- [ ] Тестовое безопасное событие дошло до целевой системы без PII, содержимого корзины,
      поискового запроса и query URL.
- [ ] Назначены владельцы алертов, каналы реакции и пороги.

## Развёртывание и откат

- [ ] Выбран runtime, совместимый с итоговым SSR/prerender artifact.
- [ ] Артефакт имеет неизменяемый version/revision и может быть повторно развёрнут.
- [ ] Политика CDN-кеша и инвалидации проверена на staging.
- [ ] Зафиксированы предыдущая стабильная версия и совместимая конфигурация.
- [ ] Процедура rollback отрепетирована; после отката выполняется smoke-тест.
- [ ] Проверена совместимость отката с версией persisted-корзины.
- [ ] Ответственные за go/no-go и rollback подтвердили релиз.
