# Current development roadmap

Statuses describe the implemented storefront, not the aspirational audit backlog. Source of truth: `.kombai/` reports, current code, `docs/adr/0001-rendering-strategy.md`, and `AGENTS.md`.

## Phase 0 — Discovery and blocking fixes — VERIFIED

**Goal:** remove blocking semantic/dev-preview issues and record the initial route/indexing policy.

- One application `main#main-content`, skip link, bootstrap error fallback, reconciled route copy/tests.
- `robots.txt` and `sitemap.xml` are generated by Vite; the route/indexing matrix is documented.
- React/Vite/FSD/API contracts remained unchanged. SSR/prerender and real HTTP `404/500` are explicitly outside this phase.
- **Checks:** Phase 0 report records passing typecheck, lint, build and production-output verification; later E2E/axe reports resolve its historical browser/test blockers.

## Phase 1 — UI foundation — VERIFIED

**Goal:** establish reusable visual and accessibility foundations.

- Tokens provide palette, typography, spacing, responsive/container, focus and control-size values.
- Shared empty/error states support page and inline variants; link/status colors, interactive sizing and active/focus states are token-based.
- Responsive home/category sizing and control ergonomics were corrected without changing the product architecture.
- **Checks:** current `typecheck`, `lint`, unit/integration suite (33 files / 119 tests), full Playwright suite (22 tests) and axe suite (6 tests) pass.

## Phase 2 — Core components and product discovery — VERIFIED

**Goal:** make catalog discovery and key navigation actions functional and accessible.

- Persistent header search navigates to catalog URL state; catalog filters update catalog state/API results; product cards offer a safe direct add-to-cart action when a target variant exists.
- Mobile menu now has dialog semantics, focus trap, Escape/backdrop close, `aria-controls`, and focus restoration.
- Catalog filter controls have accessible labels; shared dialog focus handling is covered by tests.
- **Checks:** current `npm run typecheck`, `npm run lint`, `npm run test` (33 files / 119 tests), `npm run test:e2e` (22 tests) and `npm run test:a11y` (6 tests) pass.
